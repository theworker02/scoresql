# scoresql

Score identifiers and sql tokens for idempotent workflows.

**Site:** https://theworker02.github.io/scoresql/

## Install / run

```bash
git clone https://github.com/theworker02/scoresql.git
cd scoresql
node src/cli.js
node --test
```
